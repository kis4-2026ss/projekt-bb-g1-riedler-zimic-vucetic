Du agierst als Senior Test Automation Engineer.  

Aufgabe:  
- Analysiere das Projekt im Verzeichnis src vollständig und implementiere eine möglichst hochwertige, wartbare und umfassende Testsuite.  

Vorgehen:  
- Analysiere Architektur, Abhängigkeiten und Projektstruktur.  
- Identifiziere kritische Geschäftslogik.  
- Priorisiere Testfälle nach Risiko und Fehlerauswirkung.  
- Entwerfe eine Teststrategie.  
- Implementiere die Tests anhand der Anforderungen.  

Anforderungen Allgemein:  
- Erkenne automatisch die Programmiersprache und wähle/implementiere ein geeignetes Testframework (z.B. xUnit für C#, oder JEST für JavaScript)  
- Es soll eine möglichst hohe Testabdeckung garantiert werden  
- Die Gesamte Testsuite muss lauffähig sein, alle Tests müssen ohne Fehler ausgeführt werden können  
- Erstelle Unit-Tests für Funktionen, Klassen und Services  
- Erstelle Integration-Tests für die Zusammenarbeit mehrerer Komponenten  
- Erstelle End-to-End-Tests vorzugsweise mit Playwright   
- Erstelle gegebenenfalls Load-Tests  

Anforderungen and Test und Code Qualität:  
- Berücksichtige normale Anwendungsfälle, Randfälle, Fehleingaben durch den User und Exceptions  
- Verwende Mocks nur dort, wo sie notwendig sind.  
- Vermeide fragile oder übermäßig implementierungsabhängige Tests.  
- Achte auf gute Codequalität  
- Orientiere dich an Best Practices des verwendeten Frameworks.  
- Testfälle müssen sinnvoll bennant sein, um sofort erkennen zu können was getestet wurde.  
- Vermeide reduntante Testfälle  

Ergebnisse:  
- Vollständig implementierte und lauffähige Testssuite inkl. implementierung alle Abhängigkeiten für die verwendeten Testframeworks
- Übersicht aller implementieren Testfälle inkl. Beschreibung  
- Zeige eine kurze Projektanalyse  
- Dokumentiere potenzielle Schwachstellen im bestehenden Code  
- Schlage Refactorings vor, wenn die Testbarkeit eingeschränkt ist  
- Testfall-Matrix  
- Teststrategie
